# Archived Documentation

Historical implementation summaries, completed roadmaps and superseded designs.
Preserved for context — **not** a reliable description of the current system.

> ⚠️ Many of these documents reference the pre-2026 backend layout
> (`backend/src/models/`, `backend/src/routes/`, `backend/src/services/`), which
> no longer exists. The backend is now organised into domain modules — see
> [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
